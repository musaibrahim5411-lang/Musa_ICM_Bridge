How it works

The bridge is a small Python server that Claude Desktop starts automatically. When Claude needs to work on the model, the server pastes the Ruby code into ICM's Ruby Script window and clicks Run. The script writes its printed output to a text file, and the bridge passes that output back to Claude.

Python 3.10+From python.org. Tick “Add python.exe to PATH” during install.

Install

  1. Put the folder somewhere permanent

    Unzip so you end up with C:\Musa_ICM_Bridge\icm_mcp_server.py. Claude Desktop runs the files from this folder every time it starts, so don't leave it in Downloads.

    C:\Musa_ICM_Bridge\
  icm_mcp_server.py          MCP server (tools Claude sees)
  icm_controller_final2.py   drives the ICM Ruby Script window
  requirements.txt           mcp, pywinauto
  install.bat                one-click setup
  register_claude.py         adds Musa_ICM_Bridge to Claude's config

  2. Run install.bat

    Double-click it. It installs the two Python packages and adds Musa_ICM_Bridge to Claude Desktop's config. Servers you already have are kept, and the old config is saved as claude_desktop_config.json.bak.

    To install the packages by hand instead:

    python -m pip install mcp pywinauto

  3. Or edit the config manually

    Open %APPDATA%\Claude\claude_desktop_config.json (in Claude Desktop: Settings → Developer → Edit Config) and add this entry inside "mcpServers". Keep the double backslashes.

    "Musa_ICM_Bridge": {
  "command": "python",
  "args": ["C:\\Musa_ICM_Bridge\\icm_mcp_server.py"]
}

    Check: if python isn't on PATH, put the full path to python.exe in "command" instead.

  4. Restart Claude Desktop completely

    Closing the window isn't enough. Right-click the Claude icon in the system tray, choose Quit, then open it again. Under Settings → Developer, Musa_ICM_Bridge should show as running.

  5. Open ICM and the Ruby Script window

    Open your network in ICM, then open the Ruby Script window with its Run button and leave it on screen. The bridge looks for a window titled InfoWorks ICM [...] and the Run button inside it.

  6. Test it

    Ask Claude in a new chat:

    Use Musa_ICM_Bridge to give me a summary of the open ICM network.

    You should get the network name and counts of nodes, links, conduits, culverts, pumps, weirs and orifices.

Tools Claude gets

ToolWhat it does
icm_run_rubyRuns any Ruby code in the open ICM session and returns what the script prints. Each script has a 30-second limit, which you can change with run_timeout in the controller file.
icm_network_summaryReturns the network name and object counts. Good for a first test.

Troubleshooting

The bridge's error messages are in Arabic. Here is what each one means and what to do.

MessageMeaningFix
مش لاقي أي نافذة InfoWorks ICM شغالةNo ICM window foundOpen ICM with a network loaded.
مش لاقي زرار 'Run'Ruby Script window isn't openOpen it and keep it visible.
لقيت زرار Run بس مش لاقي الـ text editorFound Run but not the code boxClose and reopen the Ruby Script window.
استنينا 30 ثانية ومفيش ملف نتيجةNo result within the time limitThe script is still running or crashed. Check the ICM output pane, or raise run_timeout.
Musa_ICM_Bridge missing in ClaudeThe server didn't startCheck the JSON for typos and the Python path, then quit Claude from the tray and reopen it.

While a script runs: don't click or type in the ICM window. The bridge pastes the code and presses Run for you, and anything you do in that window at the same time can interrupt it.
